# Automated Testing

This repository contains automation scripts for systems & LSDV.

## Main Script

### Run_GM.py

`Run_GM.py` allows the user to automate the Galvo Monitor algorithm trip test using OSTest.

All other scripts and utilities should be used as described by their filenames and comments within the code.

---

## Prerequisites

Before using the scripts, ensure the following software is installed:

- Python 3.x
- Git (optional, for cloning the repository)

You can obtain the code in either of the following ways:

### Option 1: Clone the Repository

```git clone <repository_url>```

### Option 2: Download ZIP

Download and extract the repository ZIP file to your desired location.

### Installation

Install Python if it is not already installed.

Open a Command Prompt, navigate to the project directory, and install the required packages:

Run:
python -m pip install -r req.txt

now the scripts are ready

### Running Scripts

cd Desktop
cd Laser_Safety_Scripts-main
cd Laser_Safety_Scripts-main
cd AutomatedTesting
cd GM_Algorithm_Test

python -i Run_GM.py
